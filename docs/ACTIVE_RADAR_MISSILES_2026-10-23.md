# 空空与高速防空导弹主动雷达寻的（2026-10-23）

## 范围

火控接管的全部空空弹及高速防空弹使用独立弹载跟踪器：

| 弹种 | 覆盖范围 |
| --- | --- |
| 远程空空弹 | 两个实体/挂架变体 |
| 中程空空弹 | 两个实体/挂架变体 |
| 近程空空弹 | 两个实体/挂架变体 |
| MICA-EM、AIM-120D | 各自独立弹种 |
| 高速防空弹 | 七种车载发射架，火控计算机及防空显示器两种接管设备 |

激光、空地、巡航、电视手动和便携式束驾的独立机制保留。

## 发射后如何工作

发射设备只交接初始目标身份、关联结构成员、位置和速度。导弹随后自行测量该目标的实时世界坐标，并通过相邻弹载测量计算速度。它不会继续复制发射雷达的目标快照，关闭雷达、切换雷达锁定目标或移除发射控制器都不会切断已发射导弹的跟踪。

`ActiveRadarSeeker` 负责目标测量和记忆；原有比例制导继续根据这些测量计算拦截航向及按需机动。各弹种的出架延迟、速度曲线、寿命、过载/转角上限不变。弹载测量可以在出架段进行，但不能提前绕过出架段的转向限制。

当前弹载探测参数统一为 12000 格、速度方向前向半角 85°，正常 20 TPS 时每秒最多测量 20 次。同一 tick 的多个设备/RWR 查询不会重复采样。超出范围、视场或目标暂不可用时，保持最后测量并外推；同一个指定目标重新可探测时恢复主动跟踪。已有诱饵命中判定仍然优先，不能被主动跟踪器自动改回原目标。

这是游戏中的主动寻的模型：独立测量已指定目标，包含距离和视场限制；不额外模拟雷达截面积、杂波及电磁传播。它不在全世界任意挑选新目标，也不把目标标识变成无限距离、全方向跟踪。

## 目标及后端处理

- 支持已加载 Sable 结构、关联结构组、普通实体以及数学导弹目标。Sable 与实体的测量统一转到世界坐标，速度包括目标载具运动。
- 空空与防空计算机保留雷达结构包围盒中心的瞄准定义；防空显示器保留结构组按质量加权的物理质心，避免更换瞄准点造成额外弹道变化。
- 每个世界、每个 tick 缓存同一目标的几何测量，多枚导弹分别执行自己的距离/视场判断。飞行中的跟踪无需调用原发射雷达。
- 防空发射关联改为验证有效的锁定雷达航迹，支持结构及实体航迹，消除只接受 Sable 结构对象的假设。发射时仍须有有效目标交接。
- 实体和数学路线共用同一个跟踪器。数学路线没有新增路径区块或目标区块的强加载；目标本身仍须存在于服务器的可查询世界中。目标卸载时回退到记忆，不会凭空模拟未知目标机动。

## 存档及指令

弹载记忆（目标、关联成员、位置、速度、采样时刻）写入导弹持久数据。实体恢复时不再要求原发射控制器仍然加载或存在；显示器发射的引信范围在发射时保存，恢复后无需向已移除的显示器读取。

数学模式的在飞记录仍保存在内存，未增加跨重启恢复功能；上述寻的记忆持久化不能替代数学飞行记录的全局保存。

无需新指令。两条运行路线仍通过以下指令选择，切换影响后续发射：

```text
/cfc missile mode entity
/cfc missile mode math
```

## 验证文件

单测入口为 `testAirDefenseIntercept`，新增 `ActiveRadarSeekerChecks` 检查独立测量、发射端快照不能覆盖弹载测量、视场/距离、失锁与重新捕获、成员和记忆序列化，并用五个空空弹族及高速防空弹对比主动跟踪与旧记忆外推的关雷达后拦截。

真实发射测试在 `ActiveRadarMissileIntegration`，复用原生挂架/发射架和生产制导：第 2 tick 移除雷达，第 5 tick 移除控制器/显示器，第 20 tick 之后让目标持续机动，第 40 tick 重建飞行制导状态以验证无发射装置时的恢复。目标分别使用真实实体和 Sable 结构，逐刻检查更新、机动上限及实体/数学轨迹对照。

测试目标的活动区块由测试夹具保持加载，Sable 结构由真实物理管线驱动位置；这些票据不由生产弹载跟踪器申请。同位置的对照弹使用原生箭矢无碰撞标记，并隔离相互爆炸伤害/冲量，防止第一枚弹的战斗部干扰第二枚弹。实体目标检查小于 0.5 格的相对扫掠距离，Sable 目标检查小于 3 格的相对扫掠距离，因此这部分是跟踪/制导拦截验收，不代表所有原生战斗部碰撞和爆炸都已穷举。

同时运行原有挂架变体、七种防空发射架库存、出架/过载、诱饵和后端一致性对照，以及 22 弹种原生运动积分、巡航实际扣弹/碰撞、集束、寿命、模式切换检查。所有测试源码均不进入交付 JAR。

## 最终结果及交付

- `testAirDefenseIntercept`：原有 282 场景、281 个按需机动飞行/行为检查及新增弹载跟踪检查通过。主动/旧记忆外推另有 12 次关雷达后变向对照，主动模式拦截，旧记忆外推脱靶超过 10 格。
- `testLowAltitudeCruise`、`testMathematicalMissiles`、`testSafetyRegressions`、`verifyShadedJar` 通过。
- 28 次主动寻的真实发射全部通过：空空弹在第 81 tick 完成拦截，最近距离约 0.018 格；防空计算机/显示器在第 112 tick 完成拦截，最近距离最大 `0.07954` 格。实体和数学模式的 1258 对位置记录差为 0。
- 另 132 次常规发射组成 66 对模式对照，13200 条轨迹记录的最大位置差为 `3.725290298461914e-9` 格、速度差为 0。22 弹种 × 120 原生 tick 积分等检查同时通过，测试服正常保存退出并得到 `BUILD SUCCESSFUL`。
- 成品核对 42 个保留类与本轮参考包逐字节相同，包括比例制导、各弹种参数、机动限制、数学积分、巡航/低空巡航、网络及数学导弹/原生粒子渲染。远程特效主类只有一句诊断日志的文字差异，反编译核对其余指令相同。本轮未修改渲染源码。测试类未打入成品。
