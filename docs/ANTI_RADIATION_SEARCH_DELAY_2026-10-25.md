# 反辐射搜索捕获延迟

开启搜索模式后，搜索框立即显示并继续慢闪；服务端经过30 tick（正常20 TPS下约1.5秒）才允许自动锁定。倒计时结束时，使用当前挂架搜索范围和最新准星/飞控方向圈位置选择工作雷达。无需再次按键。

关闭后重新开启会重新等待完整30 tick。相机更新不会重置倒计时。等待期间没有有效锁定，不能绕过锁定条件发射。该修改不改变已有有效锁定、框内择近、挂架朝向或数学飞行参数。

编译与 `testAntiRadiation`、`testFireControlWeaponInputs`、`verifyShadedJar` 均通过。真实服务器验证在 `run-anti-radiation-delay2/server/`：逐tick确认前29 tick没有锁定，第30 tick自动锁定，搜索状态始终开启；第10 tick取消并重开后重新等待30 tick；持续相机更新不重置计时；延迟期间发射不消耗弹药。随后完整回归真实雷达识别与自动择近、强制数学飞行、100/399 tick为3马赫、400 tick不引爆销毁，均通过。

同步执行的几何/后端准备场景由测试辅助方法跳过等待；延迟边界与取消重开独立使用真实服务器tick验证。测试辅助代码不进入发行JAR。

交付包中的搜索类字节码已与编译输出核对一致。协议保持52。
