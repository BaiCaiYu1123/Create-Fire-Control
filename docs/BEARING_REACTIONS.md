# 反作用力方案撤回记录

此文记录旧人工冲量方案的撤回。当前重做版已改用原生关节与有限扭矩伺服，见 [稳定器重做记录](STABILIZER_REBUILD.md)。

2026-10-01：用户在游戏内使用物理手杖接触绑定炮塔后，整车剧烈振荡并
飞起。此前新增的人工冲量反馈已撤回，恢复加入反馈之前的稳定器行为。
原生物理耦合目标尚未完成。

原稳定器在火控绑定后移除 Simulated 的原生旋转约束，每个物理子步通过
`teleport` 修正姿态，并用 `resetVelocity` 清零结构速度。尝试的反馈方案
把清零前的 `m * v` 和旋转动量传给承载载具，却仍然保留子结构的姿态
强制修正和速度清零。

Simulated 1.3.2 的 `PhysicsStaffServerHandler.DragSession` 创建从静态世界
到被抓取结构的 `FreeConstraintConfiguration`，在三个平移轴和三个旋转轴
上持续设置弹簧电机，配置刚度与阻尼，且没有显式最大电机力限制。
所以物理手杖产生的是持续的伺服作用，不是一次性的外部冲量。

人工反馈使用清零前的全部速度，无法区分手杖伺服、其他约束、碰撞与
单次后坐产生的速度。同时，子结构没有承载载具的实际速度，手杖无法
根据整个耦合系统的运动正确计算阻尼。持续伺服与强制姿态修正因此形成
不一致的物理闭环，这与用户报告的振荡放大相符。具体游戏内力和速度
曲线尚未采集，不能把单次动量计算正确视为闭环稳定性验证。

先前的数学检查仅验证坐标变换、偏心力矩和嵌套路由，没有运行原生
求解器，也没有覆盖手杖持续拖动。相关实验代码和测试任务已移除，
README 中的冲量反馈功能声明也已移除。

后续若恢复物理反作用，应让父子结构的原生关节和火控电机共同参与
同一次物理求解，保留实际运动速度，并以世界空间瞄准目标驱动关节。
需要验证手杖持续拖动、释放、偏心抓取、重炮塔、多层轴承、焊接结构和
双向稳定，不能继续把清零的全部速度直接反馈给车体。
