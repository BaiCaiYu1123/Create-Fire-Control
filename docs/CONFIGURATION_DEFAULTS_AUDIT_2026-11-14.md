# 配置功能与默认值核查（2026-11-14）

本次直接使用添加配置菜单前的火控 1.0.4 发布 JAR，以及当前面包军火库 2.7.1 原生字节码作为独立参考。测试不以新增默认值表自身作为参考答案。

## 核查依据

- 火控基准 JAR：`deliverables/idle-performance-20261113-1.0.4/create-fire-control-1.0.4.jar`。
- SHA-256：`5352a79f2359bfce556f596329ae6d1b0d3e4a17b775f3bda08336cdf100c466`。
- 面包 JAR：`mianbaos_modernwarfare-2.7.1.jar`；SHA-256：`1bd5052db988f18d35aece505b5c86e37492ad6317510bdd98722b8e902dd5d3`。
- 独立默认值测试：`ConfigurationBaselineChecks` 通过隔离类加载器读取旧 JAR 的寿命/速度/加速方法及原有配置默认值，ASM 直接读取面包原生发动机和尾焰计时比较值。

## 已纠正的问题

- 删除配置主菜单底部的存储路径说明。
- 移除当前发射路径不使用的旧虚拟导弹显示菜单和旧进阶弹道菜单，旧配置文件保留兼容用途。
- 删除已经停用的虎式转速响度补偿配置项，避免出现可调但不生效的选项。
- 移除 2.7.1 中未注册的 `agmmissile_3`、`agmmissile_4` 两个旧别名设置；旧实体别名如存在，映射到实际的 AGM III/IV 配置。实际可配置型号为 33 个（含共享实体但独立区分的 DF-26）。
- 恢复默认配置下原生超时行为，只有自定义寿命时才绕过旧的原生超时。火控最大寿命与原生清理原本是两个约束，默认保留这一关系，不擅自延长原有飞行。
- 修正 AT-5 动力段挂钩的位置，调整动力段时不再错误影响原生制导门限。
- 保留普通防空弹原有的设备差异：计算机波束路径默认 340.3 格/秒，原显示器共享防空曲线默认 680.6 格/秒；自定义速度时，两者使用指定速度。
- 未列入可配置导弹的客户端对象继续使用原来的寿命回退逻辑。
- 近炸引信、保险时间、雷达范围、HUD、炮塔限位等仍随设备保存。

## 功能调用与验证

- 150 个保留的原有配置字段默认值与旧发布 JAR 一致（其中包含未在当前菜单展示的兼容配置）。
- 33 个实际型号的默认寿命、速度、动力段均与独立参考一致；每个实体 ID 都在当前注册表中核验。
- 实际测试服务器验证：14 个机载型号的默认/修改后速度曲线、全部 3 个防空型号、全部 8 个巡航/陆攻型号、5 个反坦克型号、光学导弹、2 个弹道型号的参数消费者。
- 反坦克测试覆盖默认原生超时、3 秒/25 秒自定义寿命、延长动力段、2 倍速度；光学测试运行真实 tick 检查速度、动力段与寿命；弹道测试检查真实制导使用的各飞行阶段速度命令与自定义寿命。
- 保留设置的读写、重新加载、服务器同步、断开后本地恢复和设备独立保存测试通过。
