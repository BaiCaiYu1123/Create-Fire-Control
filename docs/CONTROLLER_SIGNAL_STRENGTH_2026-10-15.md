# 遥控器按键信号强度（0.9.1）

单键配置页在名称输入框右侧增加“输出强度”数字框，可填 0–16，默认 16；留空保存时恢复默认值。点击“保存键位”后，再保存遥控器配置。

每个按键独立设置强度。普通键按下或完整组合键触发时，无线频道、线控终端以及终端直接映射的信号均使用该值；松开或停止操控时归零。0 表示不输出红石信号。没有无线频道的线控按键同样可以保存独立强度。

旧遥控器没有此字段时自动使用 16，服务端将越界配置限制到 0–16。讲台、物品存档及 Sable 蓝图随绑定保存强度。名称、强度和频道草稿在重录按键、配对刷新或界面缩放后保留。

公开接口 `RemoteControllerApi.Binding` 新增 `signalStrength()` 和末尾强度参数；原五参数构造器保留，默认 16。动作回调仍表示按键状态。详见 [公开接口文档](REMOTE_CONTROLLER_API.md)。模组版本继续为 **0.9.1**。

验证覆盖实际 Create 接收端和线控接收端的 0、1、7、16 数值、仅线控按键独立强度、组合键释放、停止清理、旧数据默认值、带编辑令牌的服务端保存校验，以及讲台和蓝图绑定保存。
