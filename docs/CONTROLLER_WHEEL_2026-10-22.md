# 滚轮绑定与双向武器切换（0.9.1）

火控计算机的空中载具分类新增“向上循环切换武器”，放在“向下循环切换武器”上面。原来的“切换机载武器”改为向下循环，保留编号 7、原频道和旧存档绑定；向上循环使用新增编号 16。两者都会跳过没有弹药的机载武器，并在列表首尾循环。

全键盘遥控器增加 `scroll_up` 和 `scroll_down` 两个输入。火控计算机点击绑定项后滚动即可录入；可配合一个键盘键组成组合键。遥控器自身的录入页也支持滚轮，鼠标示意图增加上滚／下滚入口。高级遥控器按实时配置解析滚动方向，支持较小的高分辨率滚动量，界面显示明确的上滚／下滚名称。

滚轮按短脉冲处理。每格独立按下、释放，连续滚动会按顺序排队，避免连续滚轮状态合并后只切换一次；每次可请求 1–16 格，队列最多保留 64 格。结束操控会清空待处理滚动。无线和线控输出都遵守每键配置的强度。

新增的频道、频率和映射随物品、火控计算机存档及蓝图数据保存。公开接口提供 `Key.scroll(boolean up)`、`scroll(player, handle, up, steps)` 和 `FireControlAction.CYCLE_AIRCRAFT_WEAPON_UP`；原 `CYCLE_AIRCRAFT_WEAPON` 继续表示向下循环。模组版本保持 **0.9.1**。
