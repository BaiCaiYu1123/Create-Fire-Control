# 连接显示器的前进方向指示器兼容

连接显示器现在接受 `create_flight_control:forward_indicator`。原先火控计算机已支持该方块，但连接显示器的候选列表和 `bind` 接口没有加入它，导致绑定模式下不显示蓝框，点击也被拒绝。

使用机械动力扳手右键连接显示器，再右键前进方向指示器。未绑定设备显示蓝框，绑定后显示红框；设备列表与保存数据包含该绑定。当前每面显示器保存一个方向指示器，再绑定另一个会替换原绑定。

指示器作为备用瞄准方向和原点，方向与飞控原生模型朝向一致，并通过 Sable 姿态转换到世界坐标。显示器优先使用同一炮塔组内有效的 CBC 炮口，其次为防空发射器，最后才使用指示器。物理轴承按父子拓扑配对；没有可用武器组时，独立指示器可为第一组方向机、高低机提供备用参考。

指示器只提供方向参考，射击和弹道参数仍由已绑定的实际武器提供。移除或替换指示器后，原绑定失效。未安装飞控时不增加运行依赖。

回归入口为 `tools/forward-indicator-checks.init.gradle`，使用实际飞控 JAR 验证候选包、扳手事件、四向朝向、旋转物理子结构、显示器瞄准请求、NBT 重载和目标替换。测试类使用独立源集，不进入发行 JAR。

本轮使用整合包中的飞控 `0.8.3-mouse-fire-control-camera-fix` 和面包军火库 `2.7.1`：修改前复现连接显示器缺少候选包；修改后上述服务端回归通过，并验证有效防空发射器优先于指示器。独立运行未安装飞控的服务端也已通过。日志位于 `analysis/forward-indicator-20261115/`。
