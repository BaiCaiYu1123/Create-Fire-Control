# 连接显示器限位与界面统一

连接显示器控制的方向机和高低机全部使用火控计算机的独立物理伺服与止挡。默认参数和预览中保存的逐台参数走同一条控制路径；没有设置独立覆盖的高低机也具有实际物理俯仰止挡。

- 方向机使用各自的左右限位和中心方向；与火控计算机相同，单侧 180° 表示该侧不限位，两侧都是 180° 时允许连续旋转。
- 高低机使用各自的俯角和仰角，未覆盖时读取显示器默认值，默认值为俯角 20°、仰角 45°。允许范围与火控计算机一致：俯角 0–90°、仰角 0–89°。
- 正常瞄准、反向控制和空闲回正均经过同一组物理止挡。仅修改一台轴承的限位，不会修改另一台轴承或显示器默认值。
- 偏移直接作用于物理锚点；计算瞄准射线时使用已经移动的实际炮口，不再额外叠加一次偏移。

显示器配置页复用火控计算机的黄铜按钮绘制器，采用相同的深色标题栏、多层黄铜边框、角部铆钉、米色内容区和绿色完成按钮。反导范围滑条同步改为黄铜轨道。小窗口可滚动或拖动滚动条，“完成”和结构预览入口固定在标题栏；长转速标签会换成短标签，完整名称和单位可悬浮查看。结构预览仍只在有效物理结构上显示，透明车体和逐台设置功能继续保留。

## 物理验证

`tools/display-limits-checks.init.gradle` 在隔离服务器中建立五个真实 Rapier 轴承，经显示器生产控制方法发送超出范围的目标，并测量实际子结构朝向。

| 轴承 | 配置 | 实测收敛位置 |
| --- | --- | --- |
| 方向机 A | 左 25°、右 40°，中心朝南 | 左止挡 +25°、右止挡 −40° |
| 方向机 B | 左 15°、右 20°，中心朝西 | 绝对朝向 −75°、−110° |
| 右向安装高低机 | 俯角 12°、仰角 28° | −12°、+28° |
| 左向安装高低机 | 俯角 9°、仰角 34° | −9°、+34° |
| 没有独立设置的高低机 | 默认俯角 20°、仰角 45° | −20°、+45° |

随后仅修改方向机 A 的中心/限位和第一台高低机的俯仰范围，检查其他轴承不变，空闲回正仍受限位约束，并验证存档重载。结果与逐 tick 朝向记录位于 `analysis/display-limits-ui-20261113/physics/server/`。

```powershell
.\gradlew.bat runServer --offline --no-configuration-cache -I tools/display-limits-checks.init.gradle -PrunRoot=analysis/display-limits-ui-20261113/physics -PcbcRuntime=true -PmianbaoJar=<本地面包军火库2.7.1路径>
.\gradlew.bat runClient --offline --no-configuration-cache -I tools/structure-preview-checks.init.gradle -PrunRoot=analysis/display-limits-ui-20261113/client-final -PcbcRuntime=true -PmianbaoJar=<本地面包军火库2.7.1路径>
```

客户端场景覆盖标准与紧凑布局、短视口滚动、固定完成按钮、预览入口、半透明结构、真实物理偏移以及保存默认设置后逐台限位仍不变。测试场景类不进入发行包。
