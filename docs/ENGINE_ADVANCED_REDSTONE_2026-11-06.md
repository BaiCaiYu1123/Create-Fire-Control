# 发动机高级遥控器与红石频道控制

适用燃气轮机、99A 柴油引擎和虎式引擎。

## 高级遥控器修正

切换本体全键盘终端和高级遥控器终端时，发动机原先保留上一种终端的按键。例如全键盘的 `key_87` 留在高级遥控器配置内，会令服务端拒绝包含该旧按键的整份设置，即使刚修改的另一项是有效的高级遥控器按键。

现在绑定终端时会清除不兼容的旧按键，保留行为参数、音效参数、切换规则和红石频道。高级终端的录入值必须来自高级遥控器当前配置中的有效键盘、鼠标或滚轮输入，保存为该遥控器的逻辑按键槽。未配置或无效的输入不会录入；服务端也拒绝高级终端上的全键盘原始频道。全键盘终端继续使用本体按键链路。

## 红石频道

- 在发动机原设置页中，为“启停发动机”和每个行为分别增加频道设置，不需要先绑定遥控终端，也不要求安装 Drive By Wire。
- 行为里的频道入口为小按钮，旁边显示两个频道物品。点击后使用与现有遥控器相同的物品频率选择面板，从背包选择两个物品；顺序需与发射端一致。
- 子面板保存只更新当前编辑草稿，回到发动机设置页点击“完成”才提交；取消发动机设置页不会提交该草稿。
- 启停频道每次从无信号变为有信号时切换一次发动机，持续高电平不反复切换。
- 行为频道有信号时使用该行为的左右输出及加减速参数，断开后按原有减速规则停车。原遥控按键也能激活行为，行为优先级和切换规则沿用原实现。
- 两个物品都为空表示未配置；不会监听空频道。修改、卸载或销毁发动机时注销旧接收端，载入和改频道后读取现有信号，并定期刷新移动载具的有效范围。
- 双物品频道随发动机存档、设置数据包及蓝图方块数据保存。旧存档缺少这些字段时默认为空，不影响原按键配置。

## 验证

使用 Minecraft 1.21.1、NeoForge 21.1.230、Create 6.0.10、Sable/Rapier 2.0.6、面包军火库 2.7.0、Drive By Wire 0.3.0、高级遥控器 1.21.1-1.2.7 验证。高级遥控器依赖来自 Modrinth 公开发行文件，SHA-1：`6358da213d0eff982c3431a8d004a3e912f7957a`；该依赖和测试代码不打入发行包。

服务端夹具 `EngineInputIntegration` 使用真实 Create 红石网络及正常服务器 tick，检查三种发动机独立于终端的启停、长按、左右差速、松信号、加载时已有信号、实时改频道、空频道、NBT/网络往返，以及高级终端切换、非法按键拒绝、有效按键槽输入和超时释放。分别在不装线控和安装线控/高级遥控器的隔离服务端运行。

客户端夹具 `EngineInputClientChecks` 使用高级遥控器实际配置类，验证有效/无效按键录入、物品频道选择、无终端时保存及两种 GUI 缩放，并输出实际游戏截图。另回归原全键盘控制集成测试和发动机行为/声音、输入路由、设置数据包检查。

运行入口为 `tools/engine-input-checks.init.gradle` 和 `tools/engine-input-client-checks.init.gradle`；均需要独立 `runRoot` 和当前所需运行时依赖。发行目录中的 `verification.txt`、日志及截图记录具体测试结果。

发动机设置网络格式已更新，网络协议从 59 升为 60。客户端与服务端需要同步替换为本次同一份火控 JAR。
