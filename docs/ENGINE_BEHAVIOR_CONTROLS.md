# 发动机行为控制

2026-10-10，当前构建 `0.8.4`，网络协议 31。客户端和服务端需要使用本次同一构建。

99A 柴油发动机与 M1A2 燃气轮机共用新的行为设置界面。空手潜行右键打开；用扳手点击发动机，再点击高级信号处理器，保持原有线控终端绑定方式。

## 设置与输入

- 全局保留音效大小（0–300%）和发动机启停按键绑定。启停按键仍在按下边沿切换运行状态。
- 启停绑定下方新增“音效转速”开关，默认关闭。悬停原文：“开启后恒定发动机音效加减速度 和传动无关”。开启后同一行显示三个独立字段：加速度、减速度（分别为 0–1024 RPM/秒，分别默认 128）、最高转速幅值（0–1024 RPM，默认 256）。加速度、减速度均拒绝负值。
- 新发动机默认一个未绑定的行为；可以创建、删除行为，至少保留一个。每个行为有独立的按键和左右传动参数。
- 点击按键按钮，按住一个按键或多个组合键，再全部松开完成绑定。Backspace/Delete 清空，Esc 取消。物理按键通过现有高级遥控器配置转换为线控信号；键盘、鼠标按钮和已映射的滚轮信号使用原有映射接口。
- 每侧最大转速为 −1024 至 1024 RPM，负数表示反转。加速度、减速度拒绝负值及非有限值：0 不执行对应的加速或减速，1–1023 表示 RPM/秒，1024 表示瞬间完成对应变化。此含义同时适用于独立音效加速度、减速度。
- 每个行为的按键按钮缩短，旁边新增“切换过渡 ▾”。下拉栏按文字内容收紧宽度，分为“切入”和“离开”两行，每行横向排列默认及两个显式选项；完整说明放在悬停提示中。选择只修改当前行为的当前字段，其他行为保持原样，选择会随设置保存。
- 每次保存整体设置；取消不会提交。编辑内容在添加、删除、滚动、改变分辨率或 GUI 缩放后保留。
- 最多 64 个行为，每个行为最多 8 个不同线控信号；消息与存档均有数量边界。

## 执行规则

组合键要求全部信号同时激活。按住 W 后再按 A，会从 W 行为直接切到 W+A 行为。多个匹配行为以最后激活者为准；同一个服务端 tick 内同时激活时，优先按键更多的行为，再以列表中的后项打破相同长度的平局。释放 A 后，仍按住的 W 行为恢复执行。

切换保留两侧当前实际转速，目标始终为切换后行为的左右转速。两端均为默认时，从 A 切到 B 的整个过渡使用 A 的左右加速度、减速度；单独设置 B 的切入或 A 的切出则优先使用选择的参数。例如 A 默认、B 切入选“此行为”，A→B 使用 B 的参数。反转分别先减速经过零点，再反向加速；1024 对应的阶段瞬间完成。若中途再切换，则从当前转速根据新切换的两端设置继续过渡。首次激活使用该行为自身参数，全部松键使用最后激活行为的减速度到零。

下拉栏标题标明“加减速度来源”，切入选项为“默认”“上一行为”“此行为”；离开选项为“默认”“此行为”“下一行为”。完整的加速度、减速度来源及默认规则可悬停查看。默认表示没有单独选择；若另一端有显式选择，则默认让位。移除自动修正冲突后，所有行为的选择独立保存；冲突在执行时解决，优先采用当前触发并接管输出的行为的切入选择，切入为默认时采用上一行为的离开选择。两端均默认则沿用离开行为的加减速度。旧存档没有这两个字段时自动使用默认。

两种发动机的发电输出读取 Create 创造马达的应力容量，跟随创造马达的服务器配置；默认容量从旧的 64 SU/RPM 提升到 16384 SU/RPM。256 RPM 时为 4,194,304 SU。实际传动转速仍由行为控制，独立音效转速不提供应力。

2026-10-10 的源行为过渡调整已通过 `testEngineBehaviors` 和隔离服务器 `run_engine_transition_rates_verify` 验证。服务器覆盖四朝向柴油机、四个真实 Sable 柴油机结构及燃气轮机的 16 阶段，组合键与普通行为使用不同变化率，直接检查切换后第 2 tick 的真实输出，确认两侧分别使用离开行为的参数。交付位于 `build/dist/engine-transition-rates/create-fire-control-0.8.4.jar`。

没有匹配行为时，两侧目标为 0，分别使用最后执行行为的减速度停止。启停关闭仍保留原先立即切断动力的行为。

已有存档的旧转速、变化率及四个行驶按键会迁移为单键和组合键行为，同时保留启停绑定、音量及终端连接。新存档仅写入行为结构。

## 独立音效转速

开启“音效转速”后，柴油机与燃气轮机使用单独的有符号模拟 RPM。任何行为激活都会让模拟转速向音效最高转速变化，即使该行为两侧实际输出都为 0。任意一侧目标转速为负时，模拟目标为负的音效最高转速；左右一正一负时同样按反转处理。

行为切换保留模拟转速，按音效专属加速度、减速度连续过渡。转速绝对值升高使用加速度，绝对值降低或全部松键使用减速度。正反转切换先按减速度经过 0，再按加速度反向升速。同一 tick 的剩余时间继续积分。任一变化率设为 0 时，仅停止对应的加速或减速，另一参数仍独立生效。关闭发动机立即清零模拟状态，保留原有启停音轨。

混音使用模拟 RPM 的绝对值，方向只决定过零时的连续降速与升速。音效最高转速、变化率和模拟状态不参与 Create 传动、生成转速或应力容量计算。原有负载音效仍使用真实 SU 比例。关闭该功能则恢复音效跟随实际输出的方式；已有存档默认关闭。

服务端保存并同步模拟状态与目标，客户端按独立加减速度连续跟随服务端模拟转速快照。仅第一次收到数据时直接恢复；后续不提前跑到未来转速再向较低值回写。服务端卡顿或同步延迟时，持续升速不会出现回退，减速和反转也保留连续过渡。燃气轮机在独立模式中只用模拟转速控制 RPM 音轨和音高，取消额外的 climb 升速音高/增益包络；切入独立模式时也清除已有的包络。真实 SU 的负载音轨、负载 LFO 和音量设置保留。关闭独立模式时继续使用原有混音算法。配置通过两台发动机各自的打开/保存消息同步，本次新增行为切入/切出选择使用协议 31。上一版保存的 `SoundRpmRate` 自动迁移为相同数值的独立 `SoundRpmAcceleration`、`SoundRpmDeceleration`，后续可分别修改；新存档移除旧字段。

### 音效回落排查

此前 `.3` 修正了客户端预测/回写造成的转速回退，但用户实测独立模式仍有音效回落。最新日志确认实际加载 `.3`，并记录服务端落后 107 tick；未开启混音诊断，日志本身不能证明声音回落的原因。

按用户参数（加速度、减速度 128 RPM/秒，最高 256 RPM）检查完整生产混音时间序列：普通模式的步进同步使 climb 只在约 0–0.0445 之间变化；`.3` 独立模式把升速意图直接设为 1，使 climb 叠加最高 +3 半音和 +3 dB。到达 256 RPM 的首 tick，高档音轨音高为 1.18007，随后在转速仍为 256 时降到 1.0，增益从 0.34860 降至 0.25061。`.4` 独立模式移除这层额外包络，该段高档音轨直接保持音高 1.0、增益 0.25061。

`.4` 同时将燃气轮机启动后的怠速淡入整体提前 1 秒：理论淡入起点从 15.32 秒提前到 14.32 秒，满音量从 16.82 秒提前到 15.82 秒，保留 1.5 秒淡入和原启动音轨。实际播放时间按 20 Hz 客户端音效 tick 取整。该调整对独立模式开启和关闭都生效；混音审计逐 tick 与历史包络提前 20 tick 的结果对比。

`testEngineBehaviors` 和 `testEngineSoundRamp` 覆盖 20/10/5 TPS、临时停顿、正反向升速、反转、松键、模式切换和真实 SU 负载。CSV 位于 `build/reports/engine-sound-128-256-mix.csv`；`tools/render_engine_sound_ramp.py` 用同一组捆绑音轨、统一增益和连续相位生成普通模式、旧独立模式和修复模式的 22 秒 WAV（0–5 秒怠速，5–17 秒持续按键，17–22 秒释放）。这是混音时间序列的离线 PCM 渲染，不是用户实例的声卡录音；用户实例最终听感仍需实测。

## 界面

面板最大宽度 320 个 GUI 像素，单行为面板按内容收紧，多行为面板按可用高度扩展。音效参数仅在开启时占用一行，列表随之调整。按键和左右六个数值位于同一行为卡片；列表支持滚轮和拖动滚动条，顶部控件与底部完成/取消固定。小于 300 GUI 像素高时收紧底部留白，常见最低 240 GUI 像素高度可完整显示首行传动数值；小于 220 时进一步收紧标题区域。窗口尺寸基于 Minecraft 实际 GUI 缩放计算，列表绘制和点击限制在可视区域。
