# 红外二维范围圈修正（2026-10-25）

> 后续版本已补充 [观察角度缩放与原生鼠标目标跟随](INFRARED_VIEW_SCALE_2026-10-25.md)，此文保留上一版固定角度半径的记录。

本版修正上一版将前半球赤道作为世界圆投影的做法。该做法使正前方没有有限大圈、侧视时变成直线；这些几何检查通过不能证明符合战雷画面。

经用户指定的 ChatGPT 云端研究，公开 `rocketaamaim.nut` 使用独立的 `GimbalX/Y/Size/Visible` 与 `TrackerX/Y/Size/Visible` 绘制等半径二维圆。完整证据、固定版本链接和未知问题见 [研究报告](WAR_THUNDER_INFRARED_HUD_RESEARCH_2026-10-25.md)。公开代码没有提供上游坐标、FOV 换算或闪烁频率，研究也未完成视频逐帧核验。

## 本项目的显示规则

大圈采用二维角度提示，保持圆形。2560×1440、70° 纵向 FOV 下半径为参考图标定的 886.75 像素；小圈半径、线条颜色、透明暗边和抗锯齿剖面沿用此前标定结果。换分辨率按高度缩放，改变 GUI 比例不改变实际像素比例。FOV 缩放采用参考纵向半角正切与当前半角正切的比值。

圆心根据飞机轴在当前相机基底中的方向移动。为在 ±90° 的自定义玩法下保留有限圆，使用方位等距角度提示：相机正对机头时圆心居中，相机与机头夹角 90° 时圆心偏移一个大圈半径。偏移方向随相机的 right/up 基底变化，侧看和滚转仍是圆。整个相机视锥都在机头后方时隐藏前方范围圈。

**上述圆心映射和 FOV 缩放是本项目结合用户玩法、参考图采用的显示近似，不能称为已还原的战雷闭源算法。** 大圈表达机头相对角度，不能用它的有限半径反推实际透视视锥或导弹射程。

锁定圈中心同时受实际前半球与二维大圈限制；搜索与 HUD 共用同一限位入口。飞控普通、创造终端及自由视角继续使用安装版飞控原生目标投影、偏移与稳定路径，随后应用边界限制。原生目标不可见时不回退到固定屏幕中心。

## 继续保留的玩法

- 服务端以载具火控计算机真实世界坐标检查最大 2000 格，机头上下左右各 90°，包含边界。
- 无需雷达，忽略敌我识别；数学与实体导弹路线保留。
- 切换武器或成功发射后清锁；弹药耗尽隐藏，重新装弹从绿色搜索开始。
- 大小圈持续同相闪烁，越界失锁四闪后恢复搜索。2 Hz 是本项目近似参数；公开战雷资料未确认固定频率。保留用户要求的锁定时也持续闪烁，不能将这一自定义要求误称为战雷原样状态规则。
- 发射失败中文提示改为“红外导引头未捕获目标”；英文同步为 `Infrared seeker has not acquired a target`。

## 性能

大圈改为一次方向角计算加缓存圆周采样，去掉原有逐点世界边界透视除法及投影法线求解。继续复用数组和 1 KB 线剖面纹理，沿用 256/96/80 段预算与离屏裁剪；没有新增全屏处理、纹理分配、采集射线、网络字段或包频率。实际 CPU/GPU 帧耗时未作专门基准测试。
