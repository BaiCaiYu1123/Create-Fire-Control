# 红外 HUD、雷达与原生飞控圈分离

修复选择红外格斗弹后雷达世界目标框被隐藏、飞控目标圈被替换成绿色以及自由视角方向被传入飞控目标圈的问题。本次基于工作区当前 1.0.3 源码构建，保留已有武器观察视角的飞控接管条件。

## 行为

- 雷达继续按原有模式绘制目标框，选择红外弹不再跳过世界标记。红外捕获仍独立于雷达。
- 飞控目标方向圈继续执行原生绘制函数，保留原贴图、颜色、尺寸及原目标方向。移除对其目标方向和初始相机补偿分支的重定向，捕获坐标的钩子不再取消绘制。
- 红外正常视角沿用原生目标圈坐标；自由视角单独读取飞控鼠标方向，调用原生偏移换算及投影，结果只传给红外 HUD。原生目标坐标和红外坐标分别保存，反辐射兼容仍读取原生坐标。
- 红外投影缓存独立于飞控的绘制缓存，切换武器／会话时清空。原生目标不可见时显式禁用对应搜索，不回退到固定屏幕中间。
- 大圈缩放、小圈限位、2 km、±90°、切换／发射清锁、失锁四闪及弹药耗尽隐藏继续保留。

自由视角仅在红外已选中且鼠标飞控活动时额外投影一个方向点，反射接口首次解析后缓存；未增加全屏处理、射线采样、网络字段或包频率。

## 验证

验证使用当前安装的 `create_flight_control-neoforge-0.8.3-mouse-fire-control-camera-fix.jar` 与 `mianbaos_modernwarfare-2.7.1beta2.jar`。

- 独立冻结构建、红外检查、集成夹具编译及 `verifyShadedJar` 通过。
- 实际客户端在同步的 Sable 结构和座椅夹具上执行原生相机、HUD 回调，覆盖 16 个场景、28 张 2560×1440 截图，包含普通／创造终端、自由视角、初始投影、隐藏目标、关闭／重开、空弹药、GUI 1／4、FOV 70／110 及雷达共存。
- 6 组原生方向圈纹理参考对照通过：先以红外未选中状态调用原生绘制函数取得参考，再在红外选中状态运行完整飞控 HUD，目标圈固定区域逐像素一致；同时检查原生捕获坐标仍来自原操纵方向，红外自由视角坐标来自另一份鼠标目标投影。
- 雷达目标框及读数的固定区域在红外选中前后逐像素一致，目标轮廓存在。完整画面还有 1576 个扫掠／热栏时序相关差异，未将完整画面宣称为逐像素一致。
- 与修复前的同份 1.0.3 源码隔离基线相比，仅 4 个客户端／Mixin class 和版本元数据改变；其余 2183 个 class、所有其他资源逐字节一致，服务端制导和网络类均未改变。验证类及外部飞控类未打入成品。

客户端场景由夹具驱动真实回调，未进行完整人工飞行操作验收。日志、截图、像素与打包审计位于 `.diagnostics/infrared-hud-isolation-20261112/`。
