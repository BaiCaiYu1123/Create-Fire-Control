# 红外弹机头范围与发射重置（2026-10-25）

后续[原图样式、中心限位与绘制优化](INFRARED_STYLE_BOUNDS_2026-10-25.md)重新校准了描边、颜色与透明度，并限制搜索/锁定圈中心；本文保留机头范围与发射重置阶段的验证记录。

红外最大范围现在使用飞机机头方向的固定视锥。玩家自由观察、改变 FOV 或移动飞控目标指向圈，都不会改变飞机允许锁定的方向。大圈按当前相机投影视锥边界，斜视时会产生透视变化，背向时可以离开画面。目标只要仍在机头范围和 2000 格距离内，自由观察不会导致失锁；实际机头转开则进入原有四次失锁提示。

固定半角约 40.8°，按原始 2560×1440 参考半径 886.75 像素、70° 垂直 FOV 标定。相机与机头对齐时大圈以机头投影为中心，之后随相机姿态投影；原图的屏幕偏移不再固定施加到机头方向。小圈半径和线宽继续使用原图比例。

安装 Create: Flight Control 时，从其原生 `resolveAircraftFrame` 返回值读取飞机实际方向和原点，支持飞行控制终端和创造飞控计算机的终端适配器。搜索小圈仍读取原生 `drawTargetCircle` 的最终位置，跟随玩家的机头目标指向圈。实际机头和目标指向各用自己的数据。只在当前飞控 HUD 渲染期间捕获机体姿态，其他相机回调和过期事件不覆盖它。没有活动飞控时，机体姿态使用服务端绑定挂架及载具姿态。

每次成功接管新发射的红外弹，先给导弹保存独立目标，再立即清空发射端目标、搜索记忆与失锁动画，递增武器会话序号，并向玩家同步绿色未锁定状态。旧序号的在途视角包不能恢复刚才的锁定。后续新的视角帧可以重新捕获，没有额外人为冷却。弹药已经发射后的独立追踪不受此重置影响，恢复旧弹也不触发发射端清锁。

两款 CLOSE 红外弹继续无需雷达、忽略敌我识别，保留 2 Hz 同步常闪、四次失锁闪烁、切换武器重置、数学弹道和实体路线。
