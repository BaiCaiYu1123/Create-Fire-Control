# 红外大圈随观察角度改变直径（2026-10-25）

上一版大圈只随相机 FOV 改变尺寸，玩家转动视角时仅移动圆心。本版按用户补充，使观察方向相对机头偏转时，大圈直径也连续增大；转回机头正前方恢复原始标定尺寸。

缩放使用相机方向与飞机机头轴夹角的半角余弦倒数，同时保留原有 FOV 比例与按画面高度缩放的规则。相同角度下，上下与左右观察直径一致；相机滚转只改变偏移方向，不改变直径。此公式是本项目的显示近似，战雷公开脚本没有给出原生尺寸生成公式。

以 2560×1440、70° 纵向 FOV 为例：

| 观察方向与机头夹角 | 大圈显示直径（像素，约） |
|---|---:|
| 0° | 1773.5 |
| 60° | 2047.9 |
| 90° | 2508.1 |
| 120° | 3547.0 |

圆心偏移与当前半径共同更新，小圈中心继续限制在当前大圈之内。原生飞控普通／创造终端、自由观察的目标投影和偏移路径保留。整个画面处于机头后方时仍隐藏前半球提示。

观察角度带来的显示放大上限为 4 倍，防止接近正后方时产生无穷尺寸；该限制独立于 FOV 缩放。继续使用原有缓存纹理、圆周数组、顶点预算和离屏裁剪，只增加常数次尺寸计算，没有增加采集射线、网络字段或包频率。未进行专门的帧耗时基准测试。

实际最大锁定距离 2000 格、机头正前方 ±90°、无雷达／无敌我识别、发射与切换清锁、空弹药隐藏、失锁四闪和此前修改的提示文案保留。

验证资料位于 `.diagnostics/infrared-viewscale-20261025/`；构建使用之前的独立冻结项目，仅同步本次相关生产源码及验证文件。

## 飞控鼠标目标与自由视角

本轮同时处理用户补充的指向圈问题。红外 HUD 不再在没有原生鼠标飞控目标时额外画一个内圈；飞控目标圈的红外样式只在飞控自己的活动 HUD 绘制路径中替换。关闭鼠标飞控、失去终端或没有安装飞控时，仍可使用红外搜索／锁定 HUD，但没有伪造的飞控指向圈。

安装版飞控已更新为 `create_flight_control-neoforge-0.8.3.jar`，本轮按该版重新检查与验证。其 `freeLookCameraAngles` 先将鼠标增量累积到 `freeLookDirection`，再通过 `followCameraLook` 平滑追随。之前红外标记从 `targetFromCurrentView` 读取追随后的相机方向；现在改为读取鼠标直接控制的 `freeLookDirection`，调用飞控原有的 `targetForObservedCamera` 转换偏移，再沿用原生投影、稳定与绘制坐标。

这样鼠标先改变锁定圈方向，相机沿原生自由观察路径追上；无需重新实现鼠标采样或相机平滑，也不写入飞机的 `targetDirection` 操纵命令。初始自由方向尚未建立时沿用原生当前视角初始化入口。锁定后的红圈仍按目标结构位置跟踪。

最终整合包版本为 `0.9.3-infrared-mouse-follow`，包含本轮大圈直径变化及上述两项飞控修正。

## 验证与交付

- 红外检查及 `verifyShadedJar` 通过，覆盖直径连续增长、上下／左右等角尺寸、滚转、FOV、圆心限位及 2 km／±90° 物理范围。
- 安装版飞控 0.8.3 的实际客户端回调验证通过：14 个 2K 截图场景、7 条原生目标路径记录，包含普通／创造终端、自由观察的鼠标目标领先相机、飞行操纵命令不变、初始方向、不可见投影、GUI 1／4、FOV 70／110、空弹药、关闭与重开鼠标飞控。
- 2K 像素拟合确认 0°／60°／90°／120° 大圈半径依次增大，最大拟合半径误差小于 0.61 像素。关闭鼠标飞控的截图保留 40 像素红外搜索圈，没有原来额外的 28.5 像素飞控内圈。
- 隔离服务端真实物理目标的 1999／2000／2000.01／2001 m 捕获、跟踪、发射及同 tick 发射重采样通过；两款弹各执行实体／数学发射，共四次，弹药耗尽、补弹与恢复检查通过。
- 相比上一版二维圆包，2097 个 class 保持逐字节一致，4 个变更 class 来自本轮三个生产源码；语言资源及提示不变。验证类和外部飞控类没有打入成品。

客户端测试由夹具驱动真实游戏与飞控回调，不等同于完整人工飞行体验验收；大圈显示近似也未宣称与战雷闭源公式逐帧一致。
