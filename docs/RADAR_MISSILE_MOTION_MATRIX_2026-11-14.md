## 补测发现并修复

`matrix-before.log` 在静对动的红外/空对地发射复查处失败：清空可见性缓存后，异步查询未完成被当成失锁。

新增 CLEAR/BLOCKED/PENDING 的当前视线复查。数据待定时不允许发射，保留仍在有效时窗内的已确认锁定；确定遮挡后解除锁定。当前视线必须重新完整通过，旧结果和预测都不能授权发射。

已有移动航迹按最近观测位置预读当前及两 tick 后的预测路径，使移动中复查有机会取得数据。预测只读取数据，不产生可见性结论。续查前先检查当前已加载的方块，避免直接跳过之前检查过的路段。沿用每维度 16384 步、单雷达 4096 步、每轮 64 条射线、异步读取总额度 128、两个后台解码线程以及既有缓存容量。

最终横向用例的模拟线程单次扫描最高约 0.60 ms（现场形状的 2.7 km 视线）、1.20 ms（4 km）；这是独立测试世界的测量，不是整套模组的实机 FPS 保证。

## 其他导弹的实际覆盖与失败项

不能声称所有导弹完整发射、制导、命中及显示链路均已通过。

- 防空拦截、主动雷达导引头、制导需求、红外范围/半球/网络状态、普通防空与反坦克、低空巡航、RWR、反辐射以及数学飞行数据边界的现有独立检查通过。
- 扩展原生飞行夹具共尝试 32 种已注册实体。23 种做原生/数学对照，8 种电视/反坦克/便携防空做原生路由与 120 tick 有限状态检查；弹道实体只确认原生 API 拒绝未挂载实体。
- 对照中 19 种在首 tick 的发动机内部计时器一致性断言失败，观测为原生 0、数学 1。其余四种巡航对照继续运行至 120 tick。失败型号覆盖高性能防空、远/中/近空空、MICA、AIM-120、四种 AGM、激光、四种陆基和反辐射。测试保留这些失败，没有删除断言来宣称通过；尚未判定这是对照前置条件、接口变化还是实际行为差异。
- 完整原生发射夹具还在远程空空弹出架速度断言处失败。当前模型含延迟点火流程，不能直接把该失败解释为新遮挡代码导致的故障，也不能算作发射链路已通过。
- 电视导弹手动相机操纵、弹道/DF26 挂载到落点、所有弹型每个发射后分支和真机渲染，没有完成本轮全流程验证。

证据：`all-missiles-final2.log`、`all-missile-world-refs.log`，以及 `run_all_missile_world_refs/server/missile-model-failures.txt`。原生对照保留全套世界 tick 和注册实体，失败按型号汇总，防止第一项失败掩盖后续型号。原生/数学对照套件整体结果为 FAILED。
