# 原生关节与联合预测稳定器

本文件记录上一轮实现。本轮按最新要求改为独立轴反馈与世界到子体驱动，取消驱动电机向车体的直接反向力矩。
当前实现及验收见 [独立轴修复记录](STABILIZER_INDEPENDENT_AXES_2026-10-03.md)。以下反作用与跨轴矩阵描述不代表当前生产路径。

更新日期：2026-10-03。继续使用现有 Sable 2.0.5 / 航空学 1.3.2 后端。
当前修订保留真实铰链、有限电机扭矩、反作用、俯仰止挡和原有火控接口；
稳定补偿与操作者头瞄转速分别计算。它已经改善持续转动时必须等车体停止才归正的问题，
但不能承诺任意载荷、接触和外力下数学意义的零误差。

## 偏差原因和新执行方式

仅按车体姿态或角速度反推关节目标，不能预测本次求解中的实际车体运动：
炮塔电机反作用、另一个炮塔、手杖的世界电机、关节位置修正和原生陀螺项会共同改变结果。
直接改结构姿态或清速度会与手杖及关节求解互相争夺控制，产生整车抽搐。

`BearingStabilizer.drive()` 继续维护原有世界指令、机械输入、主动瞄准制动、轴承偏移及限位。
随后，`RapierServoPlanningMixin` 在全部物理 actors 已排队指令后、`Rapier3D.step` 前调用联合规划：

1. 按共同车体组成组件，用同一快照读取真实质量、惯量、质心姿态和原生速度。
2. `SableServoConstraints` 只读记录关节创建、删除和电机命令，镜像原生关节图的实际顺序。
   删除关节时同步最后一个图边移入空位；删除刚体时按原生出边、入边邻接顺序删除。
   图边顺序不同于创建时间及原生 handle 的 arena 索引。
   成对无碰撞链接没有求解行，忽略它们的运动耦合；未知物理连接使整个组件回退。
3. `ArticulatedServoPredictor` 模拟现有铰链和世界 FreeConstraint 的离散响应，
   包括有限电机冲量、锁轴 Jacobian、PGS、位置偏置和惯量耦合。
4. `NativeGyroForecast` 预测 Sable 原 fork 的每完整物理步陀螺速度更新。
   主惯量顺序及 float 中间运算按 glamx 0.1 和原 DLL 核对；这里只改变预测快照。
5. `ArticulatedServoSolver` 用有限差分建立电机目标到炮管世界射线误差的响应矩阵，
   最多三次 Newton 校正。它只替换自有关节的电机目标，物理反作用仍完全由原关节产生。

所有模型坐标共同减去车体质心，避免约两千万格的子层坐标进入求解。
当前模型上限为每组件 8 根受控轴、17 个刚体。模型失败、未知连接、缺失快照、
限位迁移或不可达目标均保留原伺服命令，不删除别的模组的连接。
求解残差容差为 `1e-5 rad`；每次校正最多 `0.05 rad`，总校正最多 `0.15 rad`。
这属于电机目标计算边界，服务端 `< 0.05°` 精度断言仍独立执行。

静止车体沿用原休眠路径，避免持续逆解 float 姿态修正阻止结构休眠。
预测内部工作缓冲区只用于本次调用，不共享可变物理状态。
边记录独立于弱引用 handle 保留，handle 被 GC 不会被误作物理关节删除。
Sable 绳索会在后端内部创建不可观测关节，遇到这类内部变化时该维度保留原控制，
释放可选预测记录；不修改或移除绳索本身。

## 双轴、反作用与多炮塔

`NativeBearingJoint` 把 Generic 单轴关节接入航空学轴承原有 handle 槽位。
`facing * Rz(π/2)` 把原生 Y 转轴映射到关节局部 X，锁住三个平移轴和其余两个旋转轴。
高低机继续校准左右安装方向和水平零位，原生止挡及目标止挡共同遵守俯仰范围。
收窄限位或编辑轴承偏移时沿用平滑迁移，解绑、心跳过期和原生重连仍管理唯一关节。

原有 AccelerationBased 电机参数保持：刚度 `I_eff * 240²`，阻尼 `I_eff * 480`，
有限扭矩 `I_eff * 3600`。`I_eff` 使用锚点处父子有效惯量，包含串联负载。
模型中锁轴使用原生关节的 550 Hz / 阻尼比 4；Sable 的 40 Hz / 5 配置是接触参数。
没有子体瞬移、清速度或重复施加关节冲量。

每根轴承保持独立的目标、限位和控制状态，同车受控电机共同进入预测。
某炮塔正在主动瞄准或制动时，其既有电机命令保持原值并参与物理模型；
另一炮塔保持世界方向时仍可以接受联合补偿，避免整车一起回退旧控制。
共用方向机的多个炮管仍按单位射线等权平均，独立高低机分别追踪自己的目标。
操作者转速只推进主动指令，零头瞄速度及没有头瞄输入时仍补偿车体运动。

手杖抓受控炮塔分支时相关轴让出电机，承重铰链继续存在；兄弟炮塔保持独立控制。
抓外部车体时全部炮塔继续补偿；释放后保留手杖赋予整车的真实动量。
普通轴承、自动防御屏、雷达、导弹、瞄具、遥控及蓝图继续使用原有入口。

## 头瞄与准星

普通头瞄使用真实炮口、实际弹药弹道和受控关节之外的车体速度求解，
实际落点预测仍使用炮口完整速度，避免把转炮自身速度反馈到瞄准解。
空射线且没有有限或锁定目标时直接使用相机世界方向，逐组包同步实测炮口直线标记；
重新命中恢复弹道落点。切换模式清除跨类型插值，避免准星仍留在地面。
逐组弹道包独占各组标记状态，普通会话包不再交替覆盖它。网络协议保持 16。

## 验证与结果

测试加载现有 Sable 2.0.5 JAR 内的原 DLL；没有定制或替换物理后端。
测试类和 JNI 加载器不进入发行 JAR。服务端使用独立生成的测试存档，
完整流程覆盖真实装配、生产控制器、CBC 命中→空射线→命中、左右高低机、
限位迁移、反作用、到位制动、手杖让控/释放、解绑、重连、解散和多炮塔。

最终服务端与原生数据见 [2026-10-03 验收记录](STABILIZER_ACCEPTANCE_2026-10-03.md)。
持续转动逐物理步测量稳定阶段，
每次换速前一秒单独作为过渡；真实手杖抓车体精度包含抓取起始子步。
公平隔离手杖测试使用超平坦世界，先验证五体已经静止，再抓取和释放车体。

已新增的独立严格检查：

- `testNativeArticulatedPrediction`：136 种双体、实际世界电机、有限 cap、求解顺序，
  包含仅刚度和仅阻尼的外部电机；位置、姿态精度和输入不被修改。
- `testNativeGyroForecast`：2538 组 diagonal、XY/XZ/YZ/full、近重根和随机合法惯量，
  不同姿态/速度，40/120 Hz；角速度误差严格不超过 `2e-5 rad/s`。
- `testNativeArticulatedTurns`：实际五体质量、惯量和锚点，40/120 Hz、
  +120/-120/+360/+30°/秒；世界射线误差严格小于 `0.05°`。
- `testNativeArticulatedSubset`：固定兄弟电机目标仍有真实运动，仅校正被选择的轴，
  16 组真实 DLL 检查及无效索引回退。
- `testNativeArticulatedSharedYaw`：真实共享方向机连接两门独立俯仰炮，40/120 Hz、
  四种持续转速，含启动和换向的每步射线、连接间距、速度及实际反作用检查。

这些新检查加入 `check`，不受 `characterizeCarrierHold` 放行参数影响。
旧 `testNativeBearing` 仍保留基本伺服与速度观察器对照，它未接入新联合规划；
其自由偏心重载高速转动仍严格 FAIL。默认 `build/check` 因此仍会失败。
`-PcharacterizeCarrierHold=true` 只使该旧检查完成其余功能验证并保留精度 FAIL，
不能作为重载精度通过。旧实验不进入生产控制。

## 保留的失败与适用范围

原五体原生夹具把固定世界支撑放在四个铰链之前；生产完整流程在铰链已经存在后
新建该支撑。按实际关节图顺序同步预测后，默认严格八阶段通过。
`testNativeArticulatedTurns -PsupportBeforeHinges=true` 保留原前序边界和相同严格断言，
40 Hz 长转动后仍可能出现车体横向失稳。顺序敏感性已复现，尚未证明全部根因。
没有通过删掉断言或改阈值把该边界变成通过。

最初新隔离目录使用普通地形，车体释放后下落到约 Y=93 时出现明显误差并失败；
相同超平坦环境的抓取及自由下落检查通过。普通地形碰撞场景的失败记录保留在
`build/articulated-strict-isolated`。不能把无碰撞保持结果当作任意撞击精度保证。

预测尚未模拟接触、原生止挡求解行及其他模组的任意外力。有限扭矩和关节可达范围
依然存在。超过配置俯仰限位时应停在止挡，不以稳定为由绕过限制。
不同车辆质量分布、焊接图、后坐力和第三方连接需要单独验证；未知连接走原控制。
尚未运行用户客户端和原车辆存档，客户端手感、具体碰撞几何及蓝图合并不能由
独立服务端结果代替。用户游戏中的旧 JAR 和存档没有被本次验收修改。

## 可参考的焊接实现

Photomancy 1.0.1 提供蓝图工具扩展接口；游戏中的焊接模式由 Synaxis 1.5.0 注册。
它的 `WeldConstraintService.spec` 在 HINGE 模式调用 `GenericConstraintSpecs.singleAngularX`，
锁住三个平移自由度和两个旋转自由度，把两端局部锚点与关节坐标系传入 Sable。
焊接初始对齐后由原生关节维持连接，不用每步瞬移。角度限位通过 `setLimit`，
碰撞设置通过 `setContactsEnabled`。自由轴需要另加电机才能主动瞄准。

本修订参考这一真实关节耦合方式，直接使用现有 Sable API：
`addConstraint`、`setFrame1/setFrame2`、`setMotor`、`setLimit`。
`getJointImpulses` 只用于观测，不重复施力；没有新增 Photomancy/Synaxis 必需依赖。
