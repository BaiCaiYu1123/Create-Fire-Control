# 结构预览：黄铜界面、透明显示与专用模型

预览页现在直接复用火控计算机的黄铜按钮和面板边框，包括深色标题栏、角部铆钉、米色内容区及绿色应用按钮。设备列表改为右侧抽拉栏，按实际设备数量决定高度；展开时小箭头贴在栏的左缘，收起后仅在屏幕右侧保留箭头，顶部不再显示“收起列表”按钮。栏下方仍是完整预览区域，编辑设备时展开设置栏。

底部操作说明、框颜色图例和加载/保存状态分别放在独立页脚的三行，预览视口与这些文字不重叠。设备高亮框改成屏幕空间的半透明细带并带半透明深色描边，不依赖显卡可能钳制为单像素的 OpenGL 线宽。工具栏的“设备框：开/关”控制所有绑定设备框的显示，不改变绑定或逐台设置；隐藏框后仍可选中设备。

预览三维场景结束后清除它自己的深度缓冲，菜单与文字提示统一绘制在模型和设备框之上。预览内的悬浮提示使用独立的半透明背景、自动换行与屏幕边界约束，避免外部提示渲染器把模型深度带入提示内容。

右键单击结构或炮塔的非设备位置会出现紧凑的“透明：开/关”开关，宽度随文字适配，高度为 16。开关只作用于选中的物理体或组装实体的当前预览，不修改游戏内设备参数。右键已绑定设备只选中该设备或打开逐台参数，不弹出透明开关。右键拖动不会旋转或平移，也不会误弹菜单；视角旋转只使用左键拖动。滚轮缩放、中键平移继续可用。

透明开关不再显示额外悬浮说明。

选中方向机时，在该设备中心绘制红色、浅色描边的“北 N”箭头。按用户要求，箭头由 44 缩至 22 GUI 单位，描边同步减细，不随结构缩放变大。北向使用与方向限位一致的方向机父结构局部 -Z，跟随父结构变换和预览视角；修改限位中心方向不会转动北向参照。箭头在模型和设备框之后、侧栏和菜单之前绘制，不受结构遮挡，也不随设备框开关隐藏。正对北向轴时使用朝外的点或朝内的叉表示深度，避免显示任意的屏幕方向。高低机及其他设备不显示此箭头；关闭预览后不再计算或绘制。

小箭头成品已通过 `analysis/preview-full-north-arrow-small.log` 的游戏检查：四种相机方向、父结构旋转、改变限位中心后的固定北向、隐藏设备框后仍显示、选中高低机时隐藏、关闭后不再计算，并人工检查默认视角与俯视截图。此前的模型、入口、逐台保存、资源重载及关闭清理检查一并通过。

## 关闭时的资源与活动

采样、实体遍历、模型刷新、预览请求和绘制只由正在打开的预览界面驱动，不注册后台 tick 或扫描任务。关闭时立即停止这些入口，释放预览 VBO、实体模型和采样数据，并清空分节缓存。再次打开时重新采样，不在后台预热。

普通游戏渲染中的兼容钩子在未捕获模型时快速返回，不访问预览用的线程局部存储、世界数据或模型缓存。残留的界面回调在关闭后直接返回，不重新采样、上传模型或发送请求。

关闭状态不分配渲染回调对象；捕获标志使用独立的轻量状态类，避免普通渲染初始化预览几何类。LT 不再安装全局预览渲染拦截，独立方块和 Create 实体中的 LT 几何都由预览专属路径直接读取。必要的兼容钩子仍保留快速状态判断，因此不把“没有后台预览工作”表述为绝对零 CPU 指令。

## 渲染修复

大结构预览不再按总量丢弃模型：移除原来的 96,000 方块、768,000 顶点、每物理体 1,024 区段和场景 2,048 区段截断，以及单个建模区段、组装实体、LT 形状的预览数量截断。缓存保留当前预览需要的完整分节，关闭时清空。

改为按工作量逐步加载：每个客户端 tick 最多处理 8 个区段，完成一个区段后检查 4ms 时间目标；原生单模型/单区段操作不可中断，因此这是软时间目标。每段模型上传后立即可见，刷新时保留上一版完整模型直到相应区段替换完成。只刷新含方块实体的区段，普通船体不会重复上传。组装实体也分批捕获，不因达到固定实体数量而遗漏。已打开预览每秒补入新到达的客户端区段；这些工作均在关闭后停止。右键拾取先检查模型包围盒，再检查命中的原生三角形，减少大船的拾取开销。

- **Create 与 CBC 组装实体**：从客户端已加载实体中收集属于当前物理结构的组装实体，以实际实体变换绘制。通过包含它的物理体、跟踪关系、原始组装锚点或 CBC 控制器定位所属结构，不把已移入实体的炮管继续当作普通 plot 方块。捕获期间临时启用普通模型和方块实体路径，完成后恢复 Flywheel 的实体部件可见位图。
- **方块建模与火控组装炮管**：模型部件直接写入预览提供的缓冲，保留部件位移、旋转、缩放、贴图及后坐变换。捕获过程不再调用面向世界画面的私有 VBO 绘制；组装实体中的方块建模炮管也使用同一路径。
- **qModeling**：在捕获范围内绕过 Flywheel 的普通渲染跳过条件，并接入它的原生 CPU 预览范围。范围和标志只影响当前线程，退出捕获后恢复。未安装 qModeling 时不会产生强依赖。
- **LittleTiles**：使用 LT/CreativeCore 的原生 `RenderBox` 四边形生成器读取细分形状、颜色和贴图，不依赖其世界区块缓存、Sodium 缓冲或完整方块占用。保留原生变形盒的轮廓。未安装 LT 时不加载其接口。

原生模型和组装炮管可以超出锚点方块；自动适配范围和右键拾取都包含实际模型几何。透明度覆盖只改变绘制通道，不重新上传所有静态模型。无关结构默认 45% 不透明度，火控设备与受控炮塔、炮管默认不透明。

## 验证

大结构实测记录：`analysis/preview-full-large-structure4.log`。真实物理结构含 196,608 方块、68 个非空区段，原生模型上传 4,720,344 个 GPU 顶点；按每个 VBO 的实际显存字节数核对顶点数，确认 256 格长结构的两端都存在。重新采样的第一刻保留完整旧模型，在采样队列尚未完成时关闭，立即清空模型、采样、动态区段和实体捕获队列，后续旧界面的 tick/render 不进行工作。常规模型与交互回归在 `analysis/preview-full-large-structure2.log` 的前 29 个阶段完成；随后修正独立 GPU 检查的缓冲绑定方式，并在上述大结构实测中通过。

隔离客户端使用用户环境中的 qModeling 2.0.6rp、LT pre238、CreativeCore 2.13.54、Yuushya Modelling 2.4.1，以及 Sable 2.0.6 / Simulated 1.3.2。测试真实创建建模数据，并通过生产火炮底座方法组装含有两种建模炮管的中口径炮，同时组装 Create 机械轴承实体。

检查包括：普通方块 GPU 模型尺寸、LT 四分之一宽/二分之一高尺寸、qmod 与两种方块建模模型非空、Create/CBC 实体模型、对实际炮管三角形右键拾取并独立切换透明显示、右键拖动不改变视角而左键仍可旋转、边缘箭头收放抽拉栏、设备框显示开关及隐藏后的选取、GPU 框线透明度、场景深度缓冲与菜单分离、黄铜控件类型、页脚与视口分离、紧凑窗口滚动、逐台参数保存与隔离、资源包重载。测试固定成品 JAR 的内容，避免共享构建目录被并发编译改写。

最新成品检查记录：`analysis/preview-full-compact-idle-fast2.log`。额外验证 Create 实体内的 LT 原生几何、16 高的紧凑透明开关、设备右键不出现透明菜单、实际鼠标悬停时没有多余说明，并在关闭后两次检查 VBO/实体/分节缓存清空；对旧界面反复调用 tick 和 render 不增加计数或刷新模型。根世界入口检查会暂时把玩家传送离结构，物理偏移检查前返回结构并等待真实服务器 tick，避免把未恢复模拟的约束当成设备故障。

相关检查：`testStructurePreview`、`testOpenControllerPayload`、`testYuushyaItemRenderPlan`、`testYuushyaShowBlockSnapshot`、`testQModelingThermal`。测试场景位于 `src/structurePreviewIntegration/`，不进入发行包。
