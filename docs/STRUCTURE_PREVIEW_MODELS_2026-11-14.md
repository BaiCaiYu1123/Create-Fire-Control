# 结构预览入口与实际方块模型

火控计算机首页的结构预览按钮固定在标题栏，点击需要先交给标题栏按钮，再判断滚动内容区域。原实现把标题栏点击提前丢弃，因此按钮可见却无法打开。入口仍要求主机处于有效物理结构上，服务端继续校验距离、编辑权限和绑定设备身份。

预览改用当前资源包的实际方块模型、模型数据、贴图 UV、颜色和朝向，不再把所有非空气方块绘制成无贴图整格方块。台阶、半砖、栅栏、活板门和炮管保留原轮廓。方块实体的原生渲染器补充轴承活动部分、炮尾及其他动态模型，并分批刷新这些部分。捕获模型时只在当前线程临时启用普通渲染路径，避免 Flywheel 的世界实例化渲染使这些部件缺失；完成捕获后立即恢复。

火控设备和方向机/高低机驱动的炮塔、炮管仍不透明，其他结构使用原贴图以 45% 不透明度绘制（按反馈从 25% 提高），兼顾辨认形状与查看内部设备。绑定设备的高亮框及右键逐台设置保留。模型仍按物理体分节上传静态 VBO，载具运动和拖动视角只更新矩阵。

缓存指纹包含方块状态与透明分类，因此相同占用下的形状、朝向变更也会在重新采样时更新。资源包重载会清空模型快照并重建 GPU 几何，避免继续使用旧贴图坐标。只读取已加载的 plot 区块；场景有分节、方块与顶点预算，达到上限时提示预览受限，不把复杂模型重新替换为整格方块。

客户端验证入口使用 `Screen.mouseClicked()` 的按钮中心坐标，不再直接调用 `Button.onPress()`。检查覆盖火控计算机、显示器、紧凑布局的标题栏入口，以及真实网络保存、逐台参数隔离、存档重载、小窗口滚动、物理结构外隐藏入口。模型检查读取实际 GPU 顶点，核对半砖半高、活板门厚度、非整数轮廓和贴图坐标，并检查方块状态变更使缓存失效、资源重载后可继续预览。验证场景位于 `src/structurePreviewIntegration/`，不会进入发行包。
