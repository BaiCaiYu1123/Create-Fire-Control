# 锁定框参考图外观

本轮在固定屏幕比例和动态读数的基础上，按用户给出的三张原始 2560×1440 截图重做锁定后的外观。按用户补充，目标名字暂不显示。

| 模式 | 原图框外沿 | 外观 |
|---|---|---|
| 光电锁定 | 73×73 像素 | 绿色连续方框，内含原图圆圈 |
| 机载雷达锁定 | 72×72 像素 | 黑色四角框，断口端点圆头，黑字带浅色描边 |
| 地面雷达锁定 | 72×72 像素 | 绿色四角框，断口端点圆头，绿字带暗色阴影 |

补充修复：地面雷达未选中目标时显示的青色角框也使用同一固定尺寸和轮廓。移除该分支旧的目标包围盒投影计算，青色框不会再随目标大小、距离或镜头缩放改变尺寸。

数字的字符间距为原图的 15 像素。距离、接近率、离地高度与方向圈分别按原图位置绘制；方向圈外径 25 像素。上述尺寸在参考分辨率下成立，整套符号按屏幕高度缩放，保持与目标大小、距离、FOV 及 Minecraft GUI 缩放无关。

新增透明纹理位于 `assets/create_fire_control/textures/gui/target_lock/`。框线及字形取自用户参考图，抠除背景后只保留符号；不再使用 Minecraft 默认字体近似数字。机载雷达的黑色与另外两种的绿色分别烘焙，光电遮挡闪烁仍控制整组符号透明度。此前的提前量连线、跟踪和数据计算保留。

生成工具为 `tools/prepare_target_lock_hud.py`，依次接收光电、机载雷达、地面雷达原始截图及细节裁图四个路径。截图本身不进入模组包。测量和静态预览位于 `build/hud-style/`。

验证包括锁定运动读数、纹理尺寸、框中心透明、四角断口和两套完整数字图集，以及 JAR 资源完整性。静态预览不等于游戏实测；尚未用游戏内截图确认每个像素的最终显示，因此不宣称已达到逐像素零偏差。

