# 机载武器观察视角

在火控计算机的按键绑定页，找到空中载具分类中的「进入导弹视角」，绑定遥控器按键或无线红石频率。此操作使用新的输入编号 45，原有绑定编号保持不变。

- 发射后按住，进入最近一次发射的机载武器的第三人称视角；移动鼠标自由环绕观察。
- 发射前提前按住，会在第一枚武器发射时进入视角。
- 持续按住时固定观察当前武器，期间发射新武器不会切换。
- 松开退出，再次按住选择最近发射的一枚。当前武器销毁也会退出，但继续按住不会自动跳到其他武器。
- 支持全部机载导弹类型、炸弹和火箭弹。集束武器的散布子弹药不会抢占母弹的观察目标。

相机只改变客户端渲染位置，武器模型使用独立的显示代理。玩家位置、朝向、相机实体和服务器区块追踪中心保持原位，不增加区块票据，也不请求武器沿途区块。未加载的地形不会因为观察而出现。

安装 Create: Flight Control 时，由火控侧兼容注入暂停观察期间的鼠标飞控输入和相机覆盖，隐藏飞控指示圈。没有修改飞控模组源码。

观察位置由有序的专用位置包和本地单调时钟驱动，不在公共导弹模型与观察数据之间切换。每帧固定一次显示位置，相机、弹体与尾迹共用；旧包和重复包会被忽略，延迟包的误差随飞行平滑校正，避免突然向后回跳。断包期间只作有限预测，恢复收包也不会直接跳回旧坐标。

尾焰按原渲染器实际变换后的尾部截面定位，包含模型旋转、偏移和当前飞行姿态。尾焰、尾烟均使用面包原版粒子及原发射密度，保留原大小、不透明度、寿命、着色方式、动画和运动参数，仅校正新粒子与当前渲染弹尾的时空偏差；没有自制锥形喷焰或重复火焰段。不给炸弹增加动力尾焰。观察距离在初版基础上增加 50%。

退出视角只结束当前粒子的跟随，不删除已生成的尾迹；旧粒子继续绘制、更新，按原版寿命自然消散。每次观察会话和导弹 UUID 独立，重进或切换武器不会拖走旧尾迹。残留尾迹的显示距离只调整投影与雾，不加载沿途区块；换世界时清理旧世界粒子。

观察状态只单发给该玩家，所有玩家继续接收公共导弹轨迹。一个玩家退出不会中断其他玩家的观察或轨迹更新。双玩家服务器回归使用实际服务器玩家与独立的抓包连接，检查私有相机包、公共轨迹包及区块状态。

## 验证

```powershell
.\gradlew.bat testWeaponViewMotion testWeaponViewSelection testFireControlWeaponInputs testMissileCameraPose testOpenControllerPayload assemble --offline
```

可选客户端检查会创建独立测试存档，检验实际相机变换、鼠标环绕、玩家位置/朝向不变、远处区块未加载、退出恢复、四种武器模型，以及约 2 马赫下的尾焰附着与连续尾烟，并在测试运行目录保存结果与截图：

```powershell
.\gradlew.bat runClient --offline '-PweaponViewClientChecks=true' '-PcbcRuntime=true' '-PrunRoot=run-weapon-view-qa' '-PmianbaoJar=完整路径/mianbaos_modernwarfare.jar' '-PflightControlJar=完整路径/create_flight_control.jar' '-Pgeckolib_version=4.9.3'
```

客户端检查还会覆盖退出保留、同刻切换／重进、炸弹不新增动力尾迹，以及 130 tick 后原生粒子全部自然到期。

位置平滑回归覆盖 30/60/144/240 FPS、200 ms 基础延迟、额外抖动、断包／乱序、重复包、单调时钟与真实掉头。客户端还会注入延迟包、旧包和公共轨迹回退，确认同帧相机与弹体坐标不变。

双玩家同步检查可在独立、已接受 EULA 的测试服务器目录运行：

```powershell
.\gradlew.bat runServer --offline '-PweaponViewServerChecks=true' '-PcbcRuntime=true' '-PrunRoot=run-weapon-view-retention' '-PmianbaoJar=完整路径/mianbaos_modernwarfare.jar'
```
