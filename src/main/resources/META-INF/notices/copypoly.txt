The editor, geometry, API, blocks, menus, packets, rendering and Sable physics
are the original CopyPoly implementations. Imported Java files have explicit
MIT/copyright headers. Copypoly.java and PolyClient.java adapt registration,
legacy aliases and the model ID. Names now read Camouflaged Polyhedral Armor.
The separate MIT renderer adapter, migrated JSON resources and ArmorEditorView camera/projection
facade in fire_control_adapter retain the original and adaptation copyright
notices. The original host armor simulation, mesh subtraction, editable mesh
screen, menu, payloads, ballistics and mixins retain Fire Control's own license.
Integration uses host build configuration, metadata,
the shared pickaxe tag and a Fire Control creative-tab reference.
Original source hashes and import details are in the separate source tree.

The bundled component retains mod ID copypoly. Its block, item and block entity
use create_fire_control:camouflaged_polyhedral_armor; registry aliases preserve
copypoly:copycat_polyhedron palettes, saved block entities, items and schematics.
Do not install another standalone CopyPoly JAR alongside this distribution.
